╚════════════════════════════════════════════════════════════════════════════════╝

Problem: Build fails for one platform
Solution: Fix the issue and run again. The script will rebuild all.
          bash scripts/build-all-platforms.sh all

Problem: Missing dependencies
Solution: Install build tools
          sudo apt-get install -y build-essential cargo rustc golang-go

Problem: Only want to rebuild one platform
Solution: Call the platform script directly
          bash scripts/build-linux-amd64.sh

Problem: Want to see what will be built
Solution: Run with no arguments to see help
          bash scripts/build-all-platforms.sh

Problem: Build takes too long
Solution: Build only needed platforms
          bash scripts/build-all-platforms.sh linux-amd64
